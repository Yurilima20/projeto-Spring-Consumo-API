# 🎬 SeriesAPI - Cadastro, Busca e Tradução Inteligente de Séries e Episódios

---

## 🚀 Visão Geral

**SeriesAPI** é uma API RESTful robusta para gerenciar séries e seus episódios.  
Permite cadastro detalhado de séries e episódios, busca inteligente por descrições e atores, além de destacar os episódios e séries mais avaliados.  

Para dar um toque especial, a API integra inteligência artificial para traduzir automaticamente a sinopse dos episódios do inglês para o português, garantindo acessibilidade para usuários brasileiros.

---

## 🔥 Funcionalidades Principais

- **Cadastro de Séries** com título, gênero, descrição e elenco  
- **Cadastro de Episódios** vinculados a séries, com título, sinopse em inglês e avaliação  
- **Busca avançada por episódios**: descrição, ator presente no episódio  
- **Busca por séries e episódios mais avaliados** (top N)  
- **Tradução automática da sinopse** do inglês para o português usando IA (OpenAI GPT)  
- API REST com endpoints claros e fáceis de usar
